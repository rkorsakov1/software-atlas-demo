Moats

Seven axes, each scored 0–5. These are Modeled judgments made in this project against the published rubric, not measurements. The rationale below says why.

  • Network 2a deep pool of PL/SQL and DBA skills makes each new deployment cheaper for the buyer.
  • Switching 5the database sits under revenue-critical and regulated systems, and migration is treated as existential — which is what supports the licensing terms.
  • Scale 4one engine and one applications suite amortise across a very large global base, and audit-driven renewals fund the next acquisition.
  • Data 2telemetry improves optimisation and support.
  • Brand 4the conservative institutional answer for a system of record.
  • Ecosystem 4consultancies and certified DBAs run large standalone businesses on Oracle.
  • Regulatory 3government and healthcare accreditations, deepened by Cerner, take entrants years to match.
Network effects2 / 5
A same-side community (content, integrations, public examples) makes the product meaningfully better once populated.
Switching costs5 / 5
The product is embedded in regulated or revenue-critical processes, and replacement risk is treated as existential by the buyer.
Scale economies4 / 5
Scale buys materially better input prices or utilisation, so the leader can price below a challenger's cost.
Data advantage2 / 5
Aggregate usage data improves defaults, benchmarks or recommendations in a way rivals would need time to match.
Brand4 / 5
The brand supports a visible price premium over functionally comparable products.
Ecosystem4 / 5
Third parties run substantial standalone businesses on the platform, and their customers become the platform's customers.
Regulatory3 / 5
Accreditation, audit history or regulator-facing filings create a multi-year barrier for new entrants.

Events (12)

  1. 1977Launch

    Software Development Laboratories, later Oracle, is founded

    Chose to implement the relational model commercially and to write it in portable C, which let one product be sold across every hardware platform.

    OracleDatabasesB01
  2. 1979Launch

    Oracle ships V2, an early commercial SQL relational database

    Started the switching-cost moat that carried Oracle through client-server, the web, SaaS and a decade-late arrival in cloud.

    OracleDatabasesB01
  3. March 1986Launch

    Oracle goes public

    Funded the field sales force that turned a technically strong database into the default enterprise purchase.

    OracleDatabasesB01
  4. June 2003Acquisitionannounced

    Oracle launches a hostile bid for PeopleSoft

    Opened eighteen months of litigation and regulatory review, and announced that enterprise applications would consolidate by force if not by agreement.

    $10.3BReported

    Bought two rivals in one, since PeopleSoft had itself acquired J.D. Edwards, and set the template for suite consolidation: buy the installed base, keep the maintenance stream, migrate the customers later.

  6. January 2006Acquisitioncompleted

    Oracle completes its acquisition of Siebel Systems

    The licensed CRM leader was absorbed rather than defeated in the market, leaving the subscription challenger to define the category on its own terms.

    OracleSiebel SystemsCRMS52
  7. January 2010Acquisitioncompleted

    Brought Java, Solaris and MySQL under one owner, putting the leading open-source database inside the leading proprietary database company and triggering a decade of forks and hedging.
