Databases

InfrastructureMatureBand L

The most durable switching-cost moat in software: data has gravity, query dialects are sticky, and the applications above the database are written against it. Oracle survived a decade of open-source competition and a late cloud entry on this alone.

What is counted

Operational and analytical database software and managed database services: relational engines, NoSQL stores, cloud data warehouses and lakehouses, counted as licence, support and consumption revenue.

Events (9)

  1. June 1969Unbundling

    IBM announces it will price software and services separately from hardware

    Created the commercial software products industry: once the dominant platform charged for software, independent vendors could compete against a priced product rather than a free one. Every later unbundling in this dataset repeats the mechanism.

    IBMOperating systemsDatabasesB03, B01
  2. 1970Launch

    Codd publishes the relational model of data

    Gave the database market a formal foundation and a portable query language, which let database software detach from any one hardware vendor.

    IBMDatabasesB01
  3. 1977Launch

    Software Development Laboratories, later Oracle, is founded

    Chose to implement the relational model commercially and to write it in portable C, which let one product be sold across every hardware platform.

    OracleDatabasesB01
  4. 1979Launch

    Oracle ships V2, an early commercial SQL relational database

    Started the switching-cost moat that carried Oracle through client-server, the web, SaaS and a decade-late arrival in cloud.

    OracleDatabasesB01
  5. March 1986Launch

    Oracle goes public

    Funded the field sales force that turned a technically strong database into the default enterprise purchase.

    OracleDatabasesB01
  6. 1991Acquisitioncompleted

    Borland acquires Ashton-Tate, maker of dBASE

    Consolidated two PC-era leaders whose products were both late to Windows; neither survived the graphical transition as an independent force.

    BorlandAshton-TateDatabasesB01
  7. 1995Launch

    MySQL is released and becomes the default database of the web

    Removed the database licence from the cost of starting an internet company, which is a precondition for the low-cost experimentation of the dot-com and SaaS eras.

    MySQL ABDatabasesB01
  8. 2001Acquisitioncompleted

    IBM acquires the Informix database business

    Consolidated the second tier of relational databases into the incumbents just as open-source engines began taking the low end.

    IBMInformixDatabasesB01
  9. January 2010Acquisitioncompleted

    Oracle completes its acquisition of Sun Microsystems

    Brought Java, Solaris and MySQL under one owner, putting the leading open-source database inside the leading proprietary database company and triggering a decade of forks and hedging.
